## 👨‍💻 About Me

I am an independent cybersecurity enthusiast and threat simulation practitioner. My work centers on understanding how adversaries operate, breaking down attack vectors step-by-step, and demonstrating how to harden systems against those exact techniques.

* 🎯 **Offensive Focus (Red Team):** Network penetration testing, wireless reconnaissance, social engineering simulations, and infrastructure mapping.
* 🛡️ **Defensive Bridge (Purple Team):** Translating adversary tactics into actionable mitigation, log analysis, and system hardening configurations.
* 🧪 **Lab Environment:** Building reproducible, isolated attack/defense lab scenarios for practical learning and research.

## 🧪 Offensive & Defensive Labs (Educational Repos)

These repositories contain proof-of-concept setups, simulated attack scenarios, and lab guides designed for hands-on learning and practical testing.

| Repository | Focus Area | Description |
| :--- | :--- | :--- |
| **`Network-Recon-Walkthrough`** | Reconnaissance | A step-by-step guide on host discovery, port scanning techniques, and banner grabbing using Nmap and Netcat. |
| **`WiFi-Security-Lab`** | Wireless Ops | Demonstration of unencrypted traffic inspection, rogue access point risks, and WPA2/WPA3 defense configurations. |
| **`Phishing-Analysis-Framework`** | Social Engineering | Dissecting targeted email vectors, header analysis, and setting up practical employee awareness simulations. |
| **`Active-Defense-Hardening`** | Purple Teaming | Scripted configurations and checklists for locking down Linux endpoints and home/SMB network perimeters. |
| **`Wireless-Signal-Mapping`** | Recon / Hardware | Proof-of-concept setups using portable hardware/drones for spatial Wi-Fi footprint analysis and signal auditing. |
